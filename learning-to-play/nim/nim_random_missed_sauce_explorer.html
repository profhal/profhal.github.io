Reading the decomposition

The four-stick finite difference uses the same residue class modulo 4: g(n) = [m(n+4) − m(n)] / 4. The exact discrete product rule is g(n) = gₒ(n) + g꜀(n), where gₒ(n) = c(n+4)[o(n+4) − o(n)]/4 and g꜀(n) = o(n)[c(n+4) − c(n)]/4.

For the growth metrics, the last plotted starting pile is 95, because n+4 must be available. The first player's concession fraction is undefined at n=4 (no sauce opportunities). Export fields were repaired using opportunities − moves = concessions and checked against the reported second-player concessions.
